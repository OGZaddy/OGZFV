## 💻 How to Launch

1. Install dependencies:
```bash
npm install
```

2. Run the bot:
```bash
node run-trading-bot-v10.2.js --profile default --asset BTC-USD
```

3. Start the backtester (optional):
```bash
node tools/optimized-backtester.js
```

4. Open the dashboard:
```bash
open ogz-ultimate-dashboard.html
```

Or use the `.bat` launcher:  
`launch-turbo-train.bat`
