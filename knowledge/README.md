# Knowledge Base

Put onboarding guides, FAQs, runbooks, and troubleshooting here. TRAI scans this folder (plus docs/ and public/) to answer support and onboarding questions even when LLMs are disabled.

Recommended:
- FAQ.md – common questions and short answers
- Getting-Started.md – quick start for each tier
- Troubleshooting.md – common errors and fixes
- Glossary.md – your product concepts (tiers, bots, indicators)

To prebuild an index for faster answers, run: npm run build:kb

This creates trai/knowledge-index.json used by TRAI at runtime.
