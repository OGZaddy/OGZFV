# Changelog Conventions

- Folder: `changelog/`
- File naming:
  - Codex entries: `YYYY-MM-DD-c.md`
  - Claude entries: `YYYY-MM-DD-cc.md`
  - If both contribute the same day, create both files.

Each entry should be actionable for the next instance. Include:
- Scope and intent
- Added/Changed/Removed/Fixed
- Operations (exact commands)
- Notes or “Next Instance Prompt” with specific guardrails
