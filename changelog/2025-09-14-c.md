# Changelog — September 14, 2025 (Codex)

Scope: Backtesting reliability, strict real-data enforcement, TRAI/backtest isolation, and WebSocket hub simplification.

- Replaced AdvancedWebSocketBroadcastSystem with SimpleWebSocketHub.
- Gated Polygon price broadcasts behind ENABLE_PRICE_BROADCAST (off by default) and filtered to dashboards/bots only.
- Fixed backtest trade flow: MDT signal mapping, pattern detector compatibility, confidence weighting.
- Added safetyMode to backtests (normal|relaxed|off); quick mode disables gates for frictionless runs.
- Enforced real data only in backtests; added generic Polygon downloader; added backtest:quick npm script.

Operations
- Restart hub: `pm2 restart ssl`
- Quick backtest: `npm run backtest:quick -- --file=data/btc-5m-sept2024.json --limit=2000`
- Auto-download + run: `npm run backtest:quick -- --symbol=X:BTCUSD --span=minute --mult=5 --from=2024-09-01 --to=2024-09-14 --limit=2000`
