## System Architecture Overview

### Core Philosophy
- **Memory-based Learning:** Patterns stored and recalled for decision making
- **Modular Design:** Each component isolated but integrated
- **Safety-first:** Multiple circuit breakers and risk limits
- **Transparency:** Real-time AI thought logging for monitoring
- **No Simulation:** All operations use real market data only

### Primary Components
1. **Trading Brain** (`core/OptimizedTradingBrain.js`) - Central decision engine
2. **Pattern Recognition** (`core/EnhancedPatternRecognition.js`) - Memory-based pattern matching
3. **Risk Management** (`core/RiskManager.js`) - Advanced drawdown protection
4. **WebSocket System** - Real-time communication infrastructure
5. **Dashboard Interface** - Valhalla GUI with live overlays
6. **Monetization Layer** - Payment processing and licensing

### Key Design Principles
- **Singleton Protection:** Prevents multiple instances from causing conflicting trades
- **Fee-aware Trading:** All profit targets account for trading fees and slippage
- **Breakeven Withdrawal:** Automatic partial exits to secure capital
- **Quantum Position Sizing:** Advanced position calculation using Kelly criterion
- **Profile-based Configuration:** Asset and strategy-specific settings
